# Zelândia Santos - Coordenação de Eventos & Garçons

Landing page institucional para a empresa de coordenação de eventos e garçons de Santo Antônio de Jesus - BA, com foco em atendimento para casamentos, formaturas, aniversários, eventos corporativos e celebrações em geral.

## Sobre o projeto

Este projeto é uma página moderna e responsiva desenvolvida em HTML, CSS e Bootstrap, com objetivo de apresentar os serviços, diferenciais, perfil profissional e facilitar o contato direto via WhatsApp.

A estrutura da página destaca:

- apresentação do serviço e localização;
- cards com os principais tipos de eventos atendidos;
- diferenciais da equipe;
- seção sobre a responsável pelo atendimento;
- FAQ para dúvidas frequentes;
- botão de contato com WhatsApp;
- visual elegante em tons escuros e dourados.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- Google Fonts

## Como executar localmente

### Opção 1: abrir diretamente no navegador

Basta abrir o arquivo `index.html` no navegador favorito.

### Opção 2: usar um servidor local

No terminal, dentro da pasta do projeto, execute:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## Customização

Você pode alterar facilmente:

- textos e mensagens da página em `index.html`;
- imagens na pasta `assets/img`;
- número do WhatsApp nos links de contato;
- cores e estilos no bloco `<style>` do arquivo HTML;
- informações de localização e identidade visual.
